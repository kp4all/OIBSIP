# To-Do Web App

Task manager with pending and completed lists.

**Tech:** HTML5, CSS3, vanilla JavaScript, localStorage

## Features
- Add tasks with the input and "Add Task" button (Enter also works)
- New tasks appear instantly under Pending Tasks
- Checkbox moves a task between Pending and Completed
- Edit a task inline (Enter or Save to confirm, Esc or Cancel to discard)
- Delete a task from either list
- Counters: "X pending" and "Y completed"
- Bonus: timestamps for when a task was added and completed
- Bonus: tasks are saved in localStorage and survive a refresh
- Friendly empty-state messages for both lists

## Run
Open `index.html` in any browser.
