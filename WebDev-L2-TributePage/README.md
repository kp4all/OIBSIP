# Tribute Page – A. P. J. Abdul Kalam

Tribute page for scientist and former President of India Dr. A. P. J. Abdul Kalam.

**Tech:** HTML5, CSS3, a few lines of JavaScript (image fallback only)

## Features
- Title with name and a one-line tagline
- Prominent portrait image
- Four-paragraph biography written in my own words
- Timeline of key moments (ordered list)
- Styled quote block
- Three different section backgrounds (navy, pale blue, saffron, white)
- Serif headings (Newsreader) with sans-serif body (Public Sans)
- Responsive layout

## Add the photo
Save a royalty-free portrait as `images/kalam.jpg` (see `images/README.txt`), then update the credit in the `<figcaption>`. Until then the page shows a monogram placeholder.

## Run
Open `index.html` in any browser.
